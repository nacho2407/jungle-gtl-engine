# 🍉 Watermelon Game

과일을 떨어뜨려 같은 종류의 과일을 합쳐 더 큰 과일을 만드는 퍼즐 게임입니다.  
플레이어는 과일의 낙하 위치를 조절하여 높은 점수를 획득하는 것을 목표로 합니다.

---

## 🎮 게임 설명

플레이어는 화면 상단에서 과일을 떨어뜨려 같은 종류의 과일을 합쳐 더 큰 과일을 만듭니다.  
같은 종류의 과일 두 개가 서로 충돌하면 하나의 더 큰 과일로 합쳐지며 점수를 획득할 수 있습니다.

맵 내부의 과일이 화면 상단의 **Game Over Line**을 넘어간 상태로 **2.5초 이상 유지되면 게임이 종료**됩니다.  
게임 종료 후 획득한 점수는 **상위 5개까지 리더보드에 기록**됩니다.

---

## 🕹️ 조작 방법

### 마우스
| 입력 | 동작 |
|---|---|
| 마우스 이동 | 과일 낙하 위치 조절 |
| 좌클릭 | 과일 떨어뜨리기 |

### 게임패드
| 입력 | 동작 |
|---|---|
| 아날로그 스틱 | 과일 낙하 위치 조절 |
| A 버튼 | 과일 떨어뜨리기 |
| 트리거 버튼 + 아날로그 스틱 | 과일 낙하 위치를 더 세밀하게 조절 |


---

## ⭐ 게임 규칙

- 같은 종류의 과일이 충돌하면 **더 큰 과일로 합쳐짐**
- 과일이 합쳐질 때 **해당 과일에 맞는 점수 획득**
- 과일이 **Game Over Line을 넘은 상태로 2.5초 유지되면 게임 종료**
- 게임 종료 시 **상위 5개 점수가 리더보드에 기록**

---

## 🏆 목표

가능한 한 많은 과일을 합쳐 **높은 점수를 획득하고 리더보드 상위권에 기록되는 것**이 목표입니다.
